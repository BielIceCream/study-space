# Release Windows

Preserve identificador, dados e UI. Use scripts desktop existentes e dependências oficiais. Compile frontend e Tauri/NSIS, verifique recursos locais, SHA-256, Authenticode e Defender quando disponíveis.

Consulte CodeIntegrity/Operational e correlacione arquivo, horário e etapa antes de atribuir falha ao Smart App Control. Não altere políticas, crie exclusões ou renomeie binários para contornar bloqueios.

Assinatura pública exige certificado ou serviço legítimo; não crie certificados autoassinados como solução pública. Não registre segredos. Separe resultado de compilação, instalação, assinatura, segurança e validação física de áudio. Não declare teste aprovado se não executado.
